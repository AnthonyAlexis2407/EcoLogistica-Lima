- **Versión:** 1.0.0

## Propósito y Justificación del Proyecto

**Fundamento de Negocio:**
"DistriRápido S.A.C." en San Juan de Lurigancho realiza 250+ entregas 
diarias, enfrentando:
- Alta congestión vehicular
- Costos operativos elevados (35% de costos totales)
- 3.5 toneladas de CO₂ mensuales
- 22% de entregas fuera de ventana de tiempo
