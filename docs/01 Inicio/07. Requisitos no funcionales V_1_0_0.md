## Formato de Escenario de Calidad (ISO/IEC 25010)

Cada requisito no funcional se especifica como un **Escenario de Calidad** con seis campos: **Fuente → Estímulo → Entorno → Artefacto → Respuesta → Medida (SLA)**. No se admiten adjetivos sin umbral numérico verificable.

Categorías cubiertas: Rendimiento, Seguridad, Disponibilidad, Usabilidad, Mantenibilidad, Escalabilidad, Accesibilidad, Seguridad de Datos, Eficiencia Energética y Portabilidad.

---

### RNF-001: Rendimiento

- **Categoría ISO/IEC 25010:** Eficiencia de desempeño
- **Fuente:** Operador logístico
- **Estímulo:** Ejecución de la planificación diaria sobre hasta 250 pedidos activos
- **Entorno:** Operación normal, carga máxima diaria vigente (250+ pedidos, en camino hacia 1,000/día según R06)
- **Artefacto:** Motor de Optimización (Algoritmo Genético / Búsqueda Tabú)
- **Respuesta:** Retornar el conjunto de rutas optimizadas
- **Medida (SLA):** Tiempo total de cómputo ≤ 45 segundos (percentil 95), conforme a R05

---

### RNF-002: Seguridad

- **Categoría ISO/IEC 25010:** Seguridad
- **Fuente:** Atacante externo
- **Estímulo:** Intento de inyección SQL, XSS o fuerza bruta sobre el endpoint de autenticación
- **Entorno:** Producción, API pública expuesta vía HTTPS
- **Artefacto:** API Gateway / capa de autenticación (JWT/OAuth2)
- **Respuesta:** Bloquear la petición, registrar el evento de auditoría y bloquear la cuenta tras el umbral de intentos (RN-001)
- **Medida (SLA):** 0% de vulnerabilidades críticas o altas del OWASP Top 10 explotables, verificado en pentest de cierre de cada iteración

---

### RNF-003: Disponibilidad

- **Categoría ISO/IEC 25010:** Confiabilidad
- **Fuente:** Infraestructura cloud
- **Estímulo:** Caída de una instancia del backend durante horario operativo
- **Entorno:** Ventana de reparto (06:00–22:00 hora Lima)
- **Artefacto:** Backend API / Base de Datos PostgreSQL
- **Respuesta:** Redirección automática del tráfico a una instancia sana (failover)
- **Medida (SLA):** RTO ≤ 60 segundos; disponibilidad ≥ 99.5% mensual dentro de la ventana operativa

---

### RNF-004: Usabilidad

- **Categoría ISO/IEC 25010:** Usabilidad
- **Fuente:** Conductor con nivel básico de alfabetización digital
- **Estímulo:** Necesidad de marcar una entrega como completada desde la app móvil
- **Entorno:** Uso en campo, dispositivo Android de gama baja, posible baja conectividad
- **Artefacto:** App móvil del conductor (PWA)
- **Respuesta:** Flujo de confirmación de entrega guiado
- **Medida (SLA):** Tarea completable en ≤ 3 toques y ≤ 20 segundos, sin capacitación previa mayor a 10 minutos (medido en pruebas de usabilidad con conductores reales)

---

### RNF-005: Mantenibilidad

- **Categoría ISO/IEC 25010:** Mantenibilidad
- **Fuente:** Equipo de desarrollo
- **Estímulo:** Necesidad de incorporar o ajustar una nueva metaheurística de optimización (ej. reemplazar Búsqueda Tabú por ACO)
- **Entorno:** Ambiente de desarrollo con suite de pruebas automatizadas
- **Artefacto:** Módulo de Optimización (capa de servicio, desacoplado del resto del backend)
- **Respuesta:** Integrar el nuevo algoritmo sin modificar los módulos de Pedidos, Flota o Dashboard
- **Medida (SLA):** Cobertura de pruebas unitarias ≥ 80% en el módulo de optimización; integración de una nueva metaheurística en ≤ 3 días-persona

---

### RNF-006: Escalabilidad

- **Categoría ISO/IEC 25010:** Capacidad / Escalabilidad
- **Fuente:** Crecimiento operativo de DistriRápido
- **Estímulo:** Incremento del volumen diario de pedidos de 250 a 1,000 (R06)
- **Entorno:** Producción, arquitectura con auto-scaling horizontal habilitado
- **Artefacto:** API Backend + Motor de Optimización
- **Respuesta:** Procesar la carga incremental sin rediseño de arquitectura
- **Medida (SLA):** Degradación de tiempos de respuesta ≤ 10% al procesar 1,000 pedidos/día frente a la línea base de 250

---

### RNF-007: Accesibilidad

- **Categoría ISO/IEC 25010:** Usabilidad (accesibilidad)
- **Fuente:** Administrador u operador con alguna limitación visual o motora
- **Estímulo:** Navegación del panel web mediante teclado o lector de pantalla
- **Entorno:** Panel web de escritorio, producción
- **Artefacto:** Panel Web (React / TypeScript)
- **Respuesta:** Todos los componentes interactivos son alcanzables y operables sin mouse, con etiquetas semánticas correctas
- **Medida (SLA):** Cumplimiento de WCAG 2.1 nivel AA, verificado con auditoría automatizada (axe-core) y manual antes de cada entrega de iteración

---

### RNF-008: Seguridad de Datos

- **Categoría ISO/IEC 25010:** Seguridad (confidencialidad de datos)
- **Fuente:** Administrador de base de datos / cumplimiento normativo
- **Estímulo:** Almacenamiento y tránsito de datos personales de conductores, bodegas y ubicaciones
- **Entorno:** Producción, cumplimiento de la Ley N° 29733 de Protección de Datos Personales
- **Artefacto:** Base de Datos PostgreSQL + capa de transporte de la API
- **Respuesta:** Cifrado de datos en reposo (AES-256) y en tránsito (TLS 1.3); anonimización de trazas de geolocalización históricas
- **Medida (SLA):** 100% de campos clasificados como personales cifrados; solicitud de eliminación/anonimización atendida en ≤ 5 días hábiles

---

### RNF-009: Eficiencia Energética

- **Categoría ISO/IEC 25010:** Eficiencia de desempeño (uso de recursos)
- **Fuente:** Equipo de sostenibilidad del proyecto
- **Estímulo:** Ejecución recurrente del motor de optimización y consultas geoespaciales
- **Entorno:** Infraestructura cloud con proveedor certificado en energía renovable
- **Artefacto:** Motor de Optimización + capa de caché (Redis)
- **Respuesta:** Reutilizar resultados de optimización recientes cuando las condiciones no cambiaron significativamente, evitando recómputo innecesario
- **Medida (SLA):** Reducción ≥ 30% en ciclos de CPU facturados por corrida de optimización frente a una implementación sin caché, medido mensualmente

---

### RNF-010: Portabilidad

- **Categoría ISO/IEC 25010:** Portabilidad
- **Fuente:** Conductor
- **Estímulo:** Instalación y uso de la app en un dispositivo Android de gama baja (≥ 2 GB RAM, Android 8.0+)
- **Entorno:** Condiciones reales de campo en SJL, El Agustino, Santa Anita y Ate, con cobertura de datos intermitente
- **Artefacto:** App móvil del conductor (PWA offline-first)
- **Respuesta:** La app se instala y ejecuta funciones críticas (ver ruta, marcar entrega) en modo offline con sincronización posterior
- **Medida (SLA):** Funcional en el 100% de los dispositivos que cumplan el requisito mínimo; evidencia offline sincronizada en ≤ 5 minutos tras recuperar señal

- RNF-002 y RNF-008 se referencian en el Documento 13 (Restricciones Multidimensionales) bajo la dimensión de Salud y Seguridad Pública, y en el Documento 09 (Reglas de Negocio, RN-001 y RN-008).
- RNF-010 sustenta el diseño offline-first de RF-004 y RF-008 del Documento 06.
